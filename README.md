Student Social Media & Mental Health Analytics
          
An interactive Power BI dashboard designed to analyze student social media usage, lifestyle patterns, academic factors, stress levels, and mental health indicators.


Project Overview

Social media has become an important part of students' daily lives and may be associated with changes in study habits, sleep patterns, physical activity, stress, and mental well-being. This project uses student-level data to explore these patterns through an interactive Power BI dashboard.The dashboard enables users to analyze student behavior across different social media platforms, academic levels, countries, genders, and purposes of social media usage.

Note: This project identifies patterns and relationships in the available data. It does not establish medical diagnoses or causal relationships between social media usage and mental health.


 Project Objectives

The main objectives of this project are to:
- Analyze social media usage patterns among students.
- Identify the most commonly used social media platforms.
- Examine average daily social media usage.
- Analyze study hours, sleep hours, and physical activity.
- Compare study and sleep patterns across academic levels.
- Understand stress-level distribution among students.
- Analyze mental health status across different student groups.
- Explore the relationship between social media usage and mental health scores.
- Provide interactive filtering for deeper analysis.

Tools & Technologies

- **Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **CSV** – Source dataset
- **Data Visualization** – Interactive charts and analytical reporting

 Dashboard Overview
    
The dashboard provides an overview of student social media behavior and related lifestyle and mental health indicators.


Key Performance Indicators

The dashboard includes:

- Average Study Hours
- Average Sleep Hours
- Average Physical Activity Hours
- Average Daily Social Media Usage Hours
- Total Number of Students
- Average Mental Health Score

Visualizations

The dashboard includes:

- Most Used Social Media Platforms
- Study & Sleep Patterns by Academic Level
- Students by Gender
- Social Media Purpose
- Stress Level Distribution
- Students by Academic Level
- Mental Health Status Distribution
- Social Media Usage vs Mental Health

Interactive Filters

Users can filter the dashboard using:

- Social Media Platform
- Country
- Purpose of Use
- Academic Level
- Gender

Key Analytical Questions
    
This dashboard is designed to answer questions such as:

1. Which social media platforms are most commonly used by students?
2. How many hours do students spend on social media each day?
3. How do study and sleep patterns vary across academic levels?
4. What is the distribution of stress levels among students?
5. How does mental health status vary across student groups?
6. Is there an observable relationship between social media usage and mental health scores?
7. How do social media habits differ by gender, country, and academic level?

 Key Insights

The dashboard can be used to identify patterns such as:

- Differences in social media usage across platforms.
- Variations in study and sleep patterns between academic levels.
- Distribution of stress levels among students.
- Differences in mental health indicators across student groups.
- Relationships between daily social media usage and mental health scores.

> Specific numerical insights are based on the dataset and dashboard filters and should be interpreted in the context of the available sample.
